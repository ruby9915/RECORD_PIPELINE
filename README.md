# 강의 정리 파이프라인

녹음·온라인 강의 영상·강의자료(PDF/PPT/Word/HWPX)·필기(텍스트)를 **한 폴더에 넣으면** 과목과 회차(날짜)별로 분류하고,
Claude 로 교정·요약한 **강의노트**를 만들어 폴더와 **노션**에 정리합니다.

```
OneDrive\문서\강의 inbox\  (+ 소리 녹음\)      ← 무엇이든 여기에 넣음
        │  run.bat
        ▼
강의정리\<과목>\<날짜(요일)>\강의노트.md       ← 회차별 복습 노트 (근거 타임스탬프·쪽수 포함)
강의정리\<과목>\<날짜(요일)>\<녹음파일>\       ← 원본·수정본 녹취록
강의정리\<과목>\자료\                          ← 분류된 강의자료 + 추출 텍스트·개요
강의정리\강의목록.md                           ← 전체 일람
노션 "강의 노트" 데이터베이스                   ← 회차마다 페이지 (노트 + 전체 녹취록)
```

> 노트북 녹음을 메인 PC로 자동 전송하려면 → [sync/README.md](sync/README.md) (Tailscale + Syncthing)

## 처리 흐름

| 입력 | 단계 | 도구 |
|---|---|---|
| 녹음 (m4a 등) | 텍스트 변환 → 과목 분류(시간표/캘린더 → 내용) → 오탈자 교정 | Whisper(GPU) + Claude |
| 영상 (mp4 등, 온라인 강의) | 소리만 추출해 녹음과 동일 처리. 수업 시간과 무관하므로 **내용으로만** 과목 분류 | Whisper + Claude |
| 자료 (pdf/pptx/docx/hwpx) | 텍스트 추출 → 과목·제목·종류·주차·주제별 쪽 범위·핵심용어 | pymupdf 등 + Claude |
| 필기 (txt/md) | 과목·날짜(내용에 있으면) 분류 | Claude |
| 회차 = 과목 + 날짜 | 관련 자료 선택 → **강의노트 생성** → 자동 검증 → 노션 업로드 | Claude |

- 실행할 때마다 **새 파일만** 처리하고, 중단되면 다음 실행에서 멈춘 단계부터 이어집니다 (`강의정리\_state.json`).
- 원본 파일은 옮기지 않고 **복사**합니다 (영상은 용량 때문에 기본적으로 복사하지 않음: `copy_video`).
- 자료에서 뽑은 핵심용어는 이후 같은 과목 녹음의 음성 인식·교정에 자동으로 쓰입니다.
- 강의노트는 입력(녹음·자료·필기)이 바뀐 회차만 다시 만듭니다. 새 자료가 들어오면 그 과목 회차들의 "관련 자료 선택"만 다시 하고, 선택 결과가 바뀐 회차만 노트를 재생성합니다.

### 강의노트 구성
핵심 개념 · 수업 흐름 · 예시와 비유 · 자료 대응(슬라이드 쪽 ↔ 녹취 구간) · 공지/과제/시험 언급 · **불확실한 부분** · 복습 질문.
모든 항목에 근거 `[hh:mm:ss]` / `(자료1 p.5)` / `(필기)` 를 달고, 녹취·자료·필기에 없는 내용은 쓰지 않도록 지시합니다.
생성 후 타임스탬프가 녹음 길이 안인지, 인용한 자료·쪽이 실제 있는지 등을 기계적으로 검사해 `경고`로 남깁니다 (노션의 "검토 필요" 체크).

## 설치 (Windows, NVIDIA GPU)
```
python -m pip install uv
python -m uv venv .venv --python 3.12
python -m uv pip install --python .venv\Scripts\python.exe -r requirements.txt
```
- Claude 호출은 **Claude Code CLI**(로그인된 claude.ai 계정, 구독 사용량에서 차감)를 씁니다. VSCode Claude Code 확장이 있으면 자동으로 찾고,
  없으면 `config.json`의 `claude.exe_path`에 claude 실행 파일 경로를 지정하세요.
- Whisper 모델은 첫 실행 때 `models\`에 자동 다운로드됩니다 (large-v3-turbo 약 1.6GB).

## 실행
| 명령 | 동작 |
|---|---|
| `run.bat` | 새 파일 처리 → 회차 노트 생성 → 노션 업로드 → 목록 갱신 |
| `run.bat --dry-run` | 처리 대상만 확인 |
| `run.bat --only "파일명"` | 그 파일만 처리 |
| `run.bat --redo --only "파일명"` | 변환부터 다시 (모델·용어 사전 변경 후) |
| `run.bat --reclassify` | 과목 분류 다시 (시간표·강의명 목록 수정 후) |
| `run.bat --session "과목\|YYYY-MM-DD" --renote` | 특정 회차 노트만 다시 생성 |
| `run.bat --no-notes` / `--no-notion` | 노트 생성 / 노션 업로드 건너뜀 |
| `run.bat --max-notes 3` | 이번 실행에서 만들 노트 수 제한 (사용량 조절) |
| `run.bat --notion-check` | 노션 토큰·부모 페이지·데이터베이스 준비 상태 확인 |

### 분류 결과 바로잡기
`강의정리\수동지정.json` 에 적고 다시 실행하면 자동 분류를 덮어씁니다 (폴더도 옮겨지고 관련 회차 노트가 다시 만들어짐).
```json
{ "녹음 (3).m4a": {"강의명": "컴퓨터 비전", "날짜": "2026-09-17"},
  "3주차.pdf":   {"강의명": "머신러닝"} }
```

## 노션 연결 (한 번만)
1. https://www.notion.so/profile/integrations 에서 **새 내부 통합(Internal integration)** 만들기 → 워크스페이스 선택 → 권한: 콘텐츠 읽기·갱신·삽입 → **시크릿 복사**
2. 노션에서 노트를 넣을 **부모 페이지**(예: `📚 강의`)를 열고 `…` 메뉴 → **연결(Connections)** → 방금 만든 통합 추가
3. 프로젝트 폴더에 `secrets.json` 생성 (git 제외됨):
   ```json
   { "notion_token": "ntn_xxxxxxxx" }
   ```
4. `config.json`의 `notion.enabled: true`, `notion.parent_page_url`에 부모 페이지 링크 입력
5. `run.bat --notion-check` → 통합 이름·부모 페이지·데이터베이스 id 가 출력되면 준비 완료. 데이터베이스 "강의 노트"는 부모 페이지 아래 자동 생성됩니다.

노션 페이지 속성: 과목(선택) · 날짜 · 자료 종류 · 키워드 · 한줄요약 · 검토 필요 · 경고. 본문 = 강의노트 + 접힌 "전체 녹취록(수정본)"·"필기 원문".
노션 API 버전은 `2022-06-28`(구버전, 계속 지원됨)을 씁니다. 노션이 이 버전 지원을 끊으면 `lecture/notion_sync.py`의 `NOTION_VERSION` 과 데이터 소스 방식으로 바꿔야 합니다.

## config.json 주요 항목
| 항목 | 설명 |
|---|---|
| `source_dirs` | 입력 폴더 목록 (하위 폴더 포함). 기본: `소리 녹음`, `강의 inbox` |
| `known_lectures` / `lecture_aliases` | 과목 정식 이름과 줄임말(소분설 등). 분류 결과를 이 이름으로 통일 |
| `timetable`, `timetable_period` | 고정 시간표와 적용 학기. 녹음 시각으로 과목을 정하는 1차 근거. **학기 바뀌면 둘 다 갱신** |
| `calendar.ics_urls` | Google 캘린더 비공개 iCal 주소 (있으면 시간표보다 우선, 휴강·보강 반영). 주소를 아는 사람은 일정 전체를 볼 수 있으니 공유 금지 |
| `whisper.hotwords_by_lecture` | 과목별 용어 사전 (인식률에 효과 큼). 자료의 핵심용어가 자동으로 더해짐 |
| `whisper.model` | `large-v3-turbo` 기본. `large-v3`는 2배 느리고 용어 사전과 함께 쓰면 본문을 누락하는 환각이 있어 쓰지 않음 |
| `notes.max_per_run` | 한 번 실행에서 만들 노트 상한 (기본 20). Claude 사용량 조절 |
| `notion.*` | 위 "노션 연결" 참고. `include_transcript: false` 면 녹취록은 노션에 올리지 않음 |
| `copy_audio` / `copy_video` | 녹음/영상 파일을 결과 폴더에 복사할지 |

## 한계 · 주의
- **지원하지 않는 형식**: 구형 `.hwp` `.ppt` `.doc` 는 읽지 못해 미분류로 가고 경고가 남습니다 (HWPX/PPTX/DOCX로 저장해 다시 넣기). 스캔 이미지 PDF도 텍스트가 없어 미분류 처리.
- **온라인 강의 영상의 슬라이드 화면**은 아직 읽지 않습니다 (소리만). 화면 인식은 다음 단계.
- **자료의 회차 배정은 내용 비교로 추정**합니다. 같은 슬라이드가 두 주에 걸쳐 쓰이면 두 회차에 모두 선택될 수 있고, 반대로 빠질 수도 있습니다. 노트 하단 "출처"에서 어떤 자료가 쓰였는지 확인하세요.
- **녹음 시각**은 파일 메타데이터 → 없으면 `수정시각 − 길이`로 추정. OneDrive 동기화로 수정시각이 바뀌면 날짜가 틀릴 수 있음 (`정보.json`의 `시각출처`).
- **노트는 음성인식 결과를 바탕**으로 하므로, 교실 뒤쪽 녹음처럼 음질이 나쁘면 "불확실한 부분"이 길어집니다. 중요한 내용은 타임스탬프로 녹음을 직접 확인하세요.
- 교정에서 결과 길이가 원문의 80~125%를 벗어나는 청크는 요약·누락 의심으로 원문을 유지하고 `경고`에 기록.
- Claude 호출은 로그인 계정 사용량에서 차감됩니다. 녹음 1시간당 대략 교정 15~20회 + 노트 1회(큰 입력) 정도.
- 이 저장소가 공개라면 `강의정리/` 아래 `수정본.txt`(녹취록)가 함께 올라갑니다 (`.gitignore` 참고). `secrets.json`은 절대 커밋하지 마세요.
